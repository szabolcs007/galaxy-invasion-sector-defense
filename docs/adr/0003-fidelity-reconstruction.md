# 0003 — Fidelity reconstruction

Date: 2026-08-15

Scoring values (Scout 30 / Warrior 40 / Bodyguard 50 / Flagship 80, double
while diving), Flagship-alert timing (20 s grace, 5 s alert, then lightning)
and the title-tune melody are reconstructed from documented rules plus
Galaxian-inspired values rather than reverse-engineered from the archived
binary; the instruction-screen OCR pass (step I of the plan) could not
legibly extract per-type values from the game's dense semigraphics font, so
the derived table stands. Sprites, by contrast, are traced pixel-exactly from
the trs-80.org 128×48 screenshots (block grid verified empirically). The
original's rare lightning near-miss is a bug and is not reproduced: the
remake's lightning is always fatal. Rationale: no accessible text source
states the exact values, and the binary-reversal cost was declined.
